# The exact source code of every library in the iOS app (iPhone and iPad),
# pinned by SHA-256 (docs/LICENSING.md, "The iOS app and the App Store").
#   - build-deps.sh builds FreeType, OpenCASCADE, libzip, nlohmann/json and
#     Eigen from these archives and refuses one whose SHA-256 differs;
#   - Qt for iOS is The Qt Company's build of this Qt version
#     (install-qt.sh); the qt* lines are its source (the Qt modules whose
#     libraries or tools the app build uses; ipad.yml's QT_VERSION must be
#     their version);
#   - mirror-sources.sh downloads all of them for a release (attached to
#     the GitHub release, as the LGPL asks);
#   - scripts/licenses/licenses.py generates the app's license texts
#     (resources/licenses/) from these archives and checks that the
#     committed texts belong to exactly these pins (ctest: licenses_check).
# PlaneGCS is vendored in third_party/planegcs (the repository is its source).
#

# then regenerate the license texts (BUILDING.md, "The iOS app's licenses").
